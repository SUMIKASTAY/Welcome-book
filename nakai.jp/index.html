テレビ (TV) の使い方

  1. 電源 ON / OFF
    リモコン上部の赤い電源ボタンを押します。
  2. チャンネルを換える
    「チャンネル」の横にある ▲ / ▼ ボタンを使用します。
  3. 音量を調節する
    「音量」の横にある ＋ / － ボタンを使用します。
  4. 方向ボタン
    必要に応じて、中央の大きな矢印（← ↑ → ↓）でメニューを操作します。

📺 ご自身のアカウントでストリーミングサービスにログインいただけます。
チェックアウト前に必ずログアウトしてください。

💡 テレビがつかない場合は、電源ケーブルが接続されているか確認し、テレビ本体の電源ボタンを押してみてください。

洗濯機（洗剤自動投入）

  1. ドアを開け、洗濯物を入れます。
    *最大容量：10kg*
  2. 電源ボタン (①) を長押しして電源を入れます。
  3. モードボタン (②) でモードを選択します：
    • 洗い — 洗濯のみ
    • すすぎ＋脱水 — すすぎと脱水のみ
    • 脱水＋乾燥 — 脱水と乾燥のみ
    • 洗濯＋乾燥 — 洗濯から乾燥まで一括（推奨）
  4. モードを選んだら、スタート / 一時停止 (③) を押して開始します。

🧴 洗剤を入れる必要はありません。
洗濯機が自動的に洗剤を投入します。

💡 *洗濯物の量によっては乾燥に時間がかかる場合があります。*
⚠ *糸くずフィルターが一杯の場合は掃除してください。また、ドラムに詰め込みすぎないようご注意ください。*

エアコン (AC)

  1. 電源 ON / OFF
    運転 / 停止 または 停止 ボタン（通常は黄色や赤）を押します。
  2. モード選択
    主なボタンから選びます：
    • 冷房 – 夏場の冷却に
    • 暖房 – 冬場の暖房に
    • 除湿 / ドライ – 湿気を取り除き、緩やかに冷やします
    • 自動 – エアコンが最適なモードを自動選択します
  3. 温度設定
    温度 ▲ / ▼ ボタンで調節します。
    推奨設定：夏場 24–27 °C、冬場 20–23 °C
  4. 風量調節
    風量 ボタンで風の強さを変更します。
  5. 風向調節
    風向 上下 / 左右 ボタンで風の向きを動かします。

💡 効率を上げるため、使用中は窓やドアを閉めてください。
⚠ 外出時や部屋を出る際は、必ずエアコンをオフにしてください。

電子レンジ

  1. ドアを開け、食べ物や飲み物を庫内の皿の上に置きます。
  2. モードを選ぶ：
    • 500W — 標準的なあたため（推奨）
    • 300W — 解凍用
    写真の強調されたモードボタンを押して切り換えます。
  3. タイマーダイヤルを回して加熱時間を設定します。
    *例：飲み物は1–2分、食事は3–5分*
  4. ダイヤルを回すと自動的に開始されます。
  5. 時間が来ると音が鳴って停止します。火傷に注意して取り出してください。

⚠ 金属容器、アルミホイル、密閉容器は絶対に使用しないでください。電子レンジ対応の容器のみ使用してください。

IHクッキングヒーター

⚠ IHクッキングヒーターはIH対応の調理器具でのみ使用できます。 調理を始める前に、鍋やフライパンを加熱部の中央に置いてください。

  1. 電源を入れる
    電源 切/入 ボタンを、音が鳴るまで長押しします。ランプが点灯します。
  2. 火力を設定する
    < / > ボタンで火力を選びます。最初は「5」が点滅した状態から始まり、 < / > で 1〜8 の範囲で設定できます。
    • 1 ≈ 300 W   ·   2 ≈ 600 W   ·   3 ≈ 1.2 kW（数字が大きいほど強火）
    *約15秒以内に設定してください。時間が過ぎると設定が自動的に取り消されます。*
  3. 加熱を開始する
    スタート ボタンを押します。「1」から設定した火力までのランプが点灯し、加熱が始まります。
  4. 調理中に火力を変える
    < / > ボタンで、いつでも火力（1〜8）を変更できます。
  5. 使い終わったら
    もう一度 スタート ボタンを押して加熱を止め、 電源 切/入 を長押しして電源を切ります（ランプが消灯します）。

⚠ 高温注意：電源を切ったあとも、天板が約50℃まで下がるまでランプが点滅し続けます。点滅中は天板に触れないでください。
💡 最後にボタンを押してから約45分で、加熱は自動的に停止します。

キッチンの水栓（センサー式）

キッチンの水栓はセンサー式です。レバーを操作する必要はありません。

  1. 水を出す
    水栓の黒いセンサー部分に手をかざすと、自動的に水が出ます。
  2. 水を止める
    もう一度黒いセンサー部分に手をかざすと、水が止まります。

💡 水が出ない場合は、センサーに十分近づけているか（約5cm以内）ご確認ください。
⚠ 水を出したままその場を離れないでください。

給湯器パネル

⚠️ 給湯器の電源はオフにしないでください — お湯の供給と暖房に必要です。
  1. 電源スイッチ (運転)
    このボタンで給湯器のON/OFFを切り換えます。
    ⚠ 滞在中は給湯器をオフにしないでください。オフにするとお湯が出なくなります。
  2. 温度調節 (給湯 温度調節)
    ▲ / ▼ ボタンでお湯の温度を変更します。
    シャワーや入浴には 40–43 °C が推奨設定です。

💡 お湯の温度を調整したい場合は、シャワーの蛇口ではなく、このパネルで調節してください。

温水洗浄便座

  1. 止 (停止 / STOP)
    止 ボタンを押すと全ての機能を停止します。
  2. おしり (洗浄)
    おしり ボタンを押すと、温水で洗浄します。
  3. ビデ (女性用)
    ビデ ボタンを押します。
  4. 強さ調節
    ＋ / − ボタンで水圧の強弱を調節します。
  5. 温水温度
    温水温度 ボタンで水の温度を変更します。
  6. 便座温度
    便座温度 ボタンで便座の温かさを調節します。

💡 一定時間が経過すると自動的に停止します。
⚠ 便座の上には立たないでください。

洗濯物の乾燥方法

洗濯物は以下の場所で乾かすことができます：

  • 4階バルコニー — 外で乾かしたい場合に最適です。
  • 浴室（室内干し） — 浴室内のバーに掛けて乾かします（推奨）。

浴室乾燥の使い方：

  1. 浴室の換気・暖房操作パネルを探します。
  2. 左の黄色いボタンを押して「乾燥」モードを開始します。
  3. タイマーを設定することもできます。設定時間が終了すると自動的に停止します。

用途に合わせてご利用ください。

ゴミの分別ルール

日本のゴミ出しルールは複雑ですが、ここではシンプルにしています。ゴミを3つのカテゴリーに分けて別々のビニール袋に入れ、駐車場にある銀色のダストボックスに入れてください。

① 可燃ごみ（燃えるごみ）
  • 生ごみ
  • 紙くず・紙コップ
  • ティッシュ
  • 飲料の紙パック
  • おむつ（汚物はトイレに流してから）
② 不燃ごみ（燃えないごみ）
  • カップ麺・コンビニ弁当の容器
  • お菓子の袋・ビニール袋
  • 発泡トレー・発泡スチロール
  • 硬プラスチック（保存容器・ハンガーなど）
  • スプレー缶（使い切って穴を開けてから）
③ 資源ごみ（ビン・カン・ペットボトル）
  • ペットボトル
  • カン
  • ビン
  • 中身を空にしてから出してください

ゴミ出しに関する注意

上記のルール以外に、不用になったスーツケースや粗大ゴミを室内に残さないでください。許可されていない物品を残された場合、処分費用を請求させていただくことがあります。分別が著しく不十分な場合（生ごみと缶などが混ざっている等）は、回収されない、または追加の処分費用をご請求することがあります。
