如果没有热水，可能是供热水面板的电源已关闭。 供热水面板位于 2楼厨房的墙面 和 1楼浴室 两处。

洗衣机・烘干机

1楼浴室内备有洗衣机・烘干机（SHARP）。

洗涤・烘干的使用方法（SHARP）

  1. 将衣物放入洗衣机。
    ※最大容量：洗涤 10kg / 烘干 6kg
  2. 投入洗涤剂。
    ※约1杯的量即可。
  3. 选择模式：
    洗涤（洗濯） / 烘干（乾燥） / 洗涤烘干（洗濯 + 乾燥）
    ※容易缩水的衣物请避免使用烘干功能。
  4. 选择程序（基本保持 标准（標準） 即可）。
    启动（START） 按此键即可开始。
  5. 所需时间：
    ・仅洗涤：约40〜60分钟
    ・洗涤＋烘干：约120〜180分钟

智能马桶盖（温水冲洗坐便器）

  • 臀部冲洗（おしり / ワイド） … 常规冲洗。
  • 妇洗（ビデ / ワイド / スーパー） … 柔和冲洗。
  • 水压调节（弱 / 強）
  • 坐圈温度 的调节
  • 热水温度 的调节
  • 喷嘴清洁（ノズルそうじ） … 自动清洁喷嘴。

使用后请务必按 停止（STOP） 按钮。
请根据个人喜好调节水温・坐圈温度等后使用。

浴缸（洗澡）操作面板

  1. 开启电源 — 运转（ON/OFF） 按此键即可开始。
  2. 自动放水 — 自动（AUTO） 按下后，会按设定的水量和温度自动放好洗澡水。
  3. 追加加热 — 水变凉时，可按 追加加热（おいだき） 键重新加热。
  • 预约放水 — 设定定时器，在指定时间烧好洗澡水。
  • 音量 — 语音提示的音量调节。
  • 时钟设置 — 当前时间的调整。

浴缸内没有热水时，请勿使用 追加加热 。
基本上只需按下 自动（AUTO） 即可安全使用。

空调使用方法

  • 开启电源 — 按绿色的 运转 / 停止 按钮。
  • 关闭电源 — 按黄色的 停止 按钮。
  • 模式切换：
    ・制冷（蓝色）
    ・制热（红色）
    ・自动（绿色）
  • 温度调节 — 温度按钮（▲ / ▼）

制热时，出风可能需要几分钟，请稍候。
外出时请务必关闭电源。

垃圾投放规则

日本的垃圾分类规则较为复杂，本住宿已简化为 只需分成3类即可。
请分别装入不同的袋子，投放到建筑前的银色垃圾箱内。

① 可燃垃圾
  • 厨余垃圾
  • 纸屑・纸杯
  • 纸巾
  • 饮料纸盒
  • 纸尿裤（污物请先冲入马桶）
② 不可燃垃圾
  • 杯面・便利店便当的容器
  • 零食袋・塑料袋
  • 泡沫托盘・泡沫塑料
  • 硬质塑料（保鲜盒・衣架等）
  • 喷雾罐（用完后打孔再丢弃）
③ 可回收垃圾（玻璃瓶・易拉罐・塑料瓶）
  • 塑料瓶（PET）
  • 易拉罐
  • 玻璃瓶
  • 请倒空内容物后再投放
