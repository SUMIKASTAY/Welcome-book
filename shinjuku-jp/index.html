給湯・お湯の設定（重要）

お湯が出ない場合は、給湯パネルの電源が切れている可能性があります。 給湯パネルは 2階キッチンの壁 と 1階浴室 の2か所にあります。

洗濯機・乾燥機

1階の浴室内に、洗濯機・乾燥機（SHARP）があります。

洗濯・乾燥の使い方（SHARP）

  1. 洗濯物を洗濯機に入れます。
    ※最大容量：洗濯 10kg / 乾燥 6kg
  2. 洗剤を投入します。
    ※カップ1杯程度で十分です。
  3. モードを選択します：
    洗濯（洗濯） / 乾燥（乾燥） / 洗濯乾燥（洗濯 + 乾燥）
    ※縮みやすい衣類は乾燥機の使用を避けてください。
  4. コースを選ぶ（基本は 標準 のままでOK）。
    スタート（START） を押します。
  5. 所要時間：
    ・洗濯のみ：約40〜60分
    ・洗濯＋乾燥：約120〜180分

ウォシュレット（温水洗浄便座）

  • おしり洗浄（おしり / ワイド） … 通常の洗浄。
  • ビデ洗浄（ビデ / ワイド / スーパー） … 優しい洗浄。
  • 水圧調整（弱 / 強）
  • 便座温度 の調整
  • 温水温度 の調整
  • ノズルそうじ … ノズルを自動クリーニングします。

使用後は必ず 停止（STOP） ボタンを押してください。
お好みに合わせて水温・座面温度などを調整してご利用ください。

浴槽（お風呂）操作パネル

  1. 電源オン — 運転（ON/OFF） を押します。
  2. 自動お湯はり — 自動（AUTO） を押すと、設定量&温度まで自動でお湯を張ります。
  3. 追いだき — 冷めた場合は おいだき ボタンで再加熱できます。
  • ふろ予約 — 指定時間にお風呂が沸くようタイマー設定。
  • 音量 — 音声案内の音量調整。
  • 時計設定 — 現在時刻の調整。

浴槽にお湯が入っていない状態で 追いだき を使わないでください。
基本は 自動（AUTO） を押すだけで安全に使えます。

エアコンの使い方

  • 電源オン — 緑色の 運転 / 停止 ボタンを押す。
  • 電源オフ — 黄色の 停止 ボタン。
  • モード切替：
    ・冷房（青）
    ・暖房（赤）
    ・自動（緑）
  • 温度調整 — 温度ボタン（▲ / ▼）

暖房の場合、風が出るまで数分かかることがあります。
外出時は必ず電源をお切りください。

ごみ出しルール

日本のごみ分別ルールは少し複雑なため、当施設ではわかりやすく 3種類に分けるだけでOKです。
それぞれ別の袋にまとめ、建物前のシルバーのダストボックスへ捨ててください。

① 可燃ごみ（燃えるごみ）
  • 生ごみ
  • 紙くず・紙コップ
  • ティッシュ
  • 飲料の紙パック
  • おむつ（汚物はトイレに流してから）
② 不燃ごみ（燃えないごみ）
  • カップ麺・コンビニ弁当の容器
  • お菓子の袋・ビニール袋
  • 発泡トレー・発泡スチロール
  • 硬プラスチック（保存容器・ハンガーなど）
  • スプレー缶（使い切って穴を開けてから）
③ 資源ごみ（ビン・カン・ペットボトル）
  • ペットボトル
  • カン
  • ビン
  • 中身を空にしてから出してください

ごみ出し ②（注意事項）
