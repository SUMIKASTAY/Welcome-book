空调 (AC)

  1. 电源 ON / OFF
    请按 運転 / 停止 或 停止 按钮（通常为黄色或红色）。
  2. 选择模式
    请从以下主要按钮中选择：
    • 冷房 – 制冷（夏季降温用）
    • 暖房 – 制热（冬季取暖用）
    • 除湿 / ドライ – 除湿 / 干燥（去除湿气，并轻微降温）
    • 自動 – 自动（空调会自动选择最合适的模式）
  3. 设定温度
    请使用 温度 ▲ / ▼ 用这些按钮调节温度。
    推荐： 24–27 °C （夏季）， 20–23 °C （冬季）。
  4. 调节风量
    请按 風量 （风量）键改变风的强弱。
  5. 调节风向
    请使用 風向 上下 / 左右 按钮，让风向上下或左右移动。

💡 使用空调时请关好门窗，以提高效率。
⚠ 离开房间或外出时，请务必 关闭 空调。

吸尘器

  1. 开启 / 关闭 — 请按上方的圆形 电源键 （红圈标示处）。
  2. 请使用 — 请在地板或地毯上轻轻推动吸尘器。 请勿吸取水或非常潮湿的区域。
  3. 清理集尘盒 — 清扫结束后，请先确认吸尘器已 关闭， 然后按下 蓝框处的卡扣 打开集尘盒，将灰尘倒入垃圾桶。
  4. 关好并放回 — 请将集尘盒盖紧，并把吸尘器放回原位。

如果感觉吸力变弱，请检查并清空集尘盒。

微波炉（SHARP）

  1. 打开机门 ，将食物或饮料放在炉内的盘子上。
  2. 选择模式:
    • 500W — 常规加热（推荐)
    • 解冻（Defrost） — 用于冷冻食品
    请按 模式键 （照片中标出）来切换模式。
  3. 转动定时旋钮 设定加热时间。
    *例：加热饮料 1–2 分钟，饭菜 3–5 分钟。
  4. 微波炉会在 自动开始** 转动旋钮后。
  5. 时间到后，会 响铃并停止。取出食物时请小心。

⚠ 请 不要将金属容器、铝箔或密闭容器 放入 微波炉内。 请只使用可用于微波炉的餐具。

电饭煲（Tiger IH）

  1. 打开上盖 ，取出内胆。
  2. 放入米和水 到内胆中。
    例：1杯米（180 ml）＋ 加水至刻度“1”。
    *此为 免洗米（無洗米）的刻度.
  3. 如果内胆外侧沾湿，请擦干后再放回电饭煲。
  4. 请将上盖完全盖好。
  5. 按“炊飯”（开始） 键开始煮饭。
  6. 煮饭约需 40–50 分钟。完成后会自动切换到 保温模式（保温） 。

煮好之后：

  • 请使用 保温（Warm） 如果打算稍后再吃，可按此键保温。
  • 请按 取消（Cancel） 可停止任何运行中的程序。

⚠ 请勿将内胆直接放在灶台上，也不要装着水放进水槽。
请务必清洗并擦干后再放回。

燃气灶与小烤箱使用说明

使用灶具时请仔细按照以下步骤操作。
⚠ 使用后请务必关火。切勿让灶具处于 无人看管的状态。

  1. 请将锅具 稳稳地放在炉头上。
  2. 按下旋钮 并保持约 3 秒 即可点火。
    • 左炉头 → 左旋钮
    • 右炉头 → 右旋钮
  3. 调节火力大小 （转动旋钮）。
  4. 要熄火时， 再次按下旋钮 直到火焰熄灭。

🔥 *如果点不着火，请松开后再试一次。* 请确认炉头周围没有水或油。

小烤箱 / 烧烤

  1. 请轻轻向前拉出烤盘。
  2. 放入食物（如有需要请使用锡纸）。
  3. 使用烤箱旋钮 （中央面板）加热。
  4. 长按旋钮点火（与灶具相同）。
  5. 加热过程中请随时留意 — 它升温非常快。
  6. 再次按下旋钮即可关闭。

⚠ 请谨慎使用 — 这个小烤箱升温极快，食物很容易烤焦。
推荐时间： 3–5 分钟，并全程留意。

💡 煮好之后：
– 关闭所有火源
– 确认没有残留的燃气味
– 待灶具冷却后清理洒落的污渍

    可以稍微打开机门排出蒸汽，有助于烘干。

🧽 洗涤剂：如需洗涤剂，请加入投放槽内。 多数餐具用标准程序即可洗净。

  • 调暗（暗） – 按下方的按键调暗灯光。

日本的垃圾规则较难理解，我们已将其简化。请将垃圾分成 3类 ，分别装入不同的塑料袋，再按下述方式投放到停车场的银色垃圾箱内。如果垃圾未妥善分类，或散落在地板上及房间各处，可能会加收清洁费或处理费。

1. 可燃垃圾
  • 厨余垃圾
  • 纸屑和纸杯
  • 纸巾
  • 饮料纸盒
  • 纸尿裤（污物请先冲入马桶）
2. 不可燃垃圾
  • 杯面容器和便当盒
  • 零食袋和塑料袋
  • 泡沫托盘和泡沫塑料
  • 硬质塑料（保鲜盒、衣架）
  • 喷雾罐（用完后打孔再丢弃）
3. 可回收垃圾
  • 塑料瓶（PET）
  • 易拉罐
  • 玻璃瓶
  • 请先倒空内容物
